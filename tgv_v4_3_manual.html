Parameter Reference Manual

TGV PSL Inspector v4.3
파라미터 설계 원리 및 사용 지침

각 파라미터가 왜 만들어졌는지, 내부에서 어떻게 동작하는지를 중심으로 설명합니다. 단순한 수치 범위 안내를 넘어 현장에서 파라미터를 조정할 때 근거 있는 판단을 내릴 수 있도록 작성되었습니다.

Overview

소프트웨어 목적

TGV PSL Inspector는 TGV(Through Glass Via) 기판의 홀(hole) 주변 PSL(Polystyrene Latex) 파티클을 현미경 이미지에서 자동으로 검출하고 계수하는 도구입니다.

PSL 파티클은 세정 공정 전·후의 오염도를 정량화하는 기준 입자로 사용됩니다. 파티클의 크기가 마이크로미터 단위이기 때문에 배율과 조명 조건에 따라 이미지 특성이 크게 달라지며, 단일 알고리즘으로 모든 조건을 커버하기 어렵습니다.

💡

v4.3의 핵심 변화 — 전역 임계값(global threshold) 방식을 폐기하고 배경 대비법(Local Residual Detection)을 도입했습니다. 헤일로(halo) 조명 영역에서도 파티클을 안정적으로 검출하는 것이 주요 동기였습니다.

Core Algorithm

핵심 알고리즘 — 배경 대비법

기존 방식의 한계: 전역 임계값

기존 v4.2 — 전역 임계값
이미지 전체에 단일 밝기 기준값(th)을 적용합니다.
픽셀 밝기 < th → 파티클

홀 주변의 헤일로 구간에서는 조명으로 인해 배경 자체가 어두워지므로, th를 낮추면 헤일로 영역 전체가 파티클로 오검출됩니다. th를 높이면 실제 파티클도 놓칩니다.
v4.3 — 배경 대비법
각 픽셀 주변의 로컬 배경을 추정한 뒤, 그것보다 얼마나 어두운가를 측정합니다.
잔차 = 로컬배경 − 현재픽셀

헤일로 구간도 가우시안 커널이 따라가므로 잔차값이 0에 가깝게 유지됩니다. 파티클만 로컬 배경보다 유의미하게 어두워 잔차가 양수가 됩니다.

알고리즘 수식

# 1단계: 로컬 배경 추정
local_bg = GaussianBlur(gray, kernel=bg_kernel, σ=bg_kernel/3)

# 2단계: 잔차 계산 (양수 = 로컬 배경보다 어두움)
residual = local_bg − gray

# 3단계: 잔차 임계값 이진화
binary = residual > res_th

파형 다이어그램

홀 중심 → 헤일로 → 배경 구간의 밝기 프로파일 (가로축: 픽셀 위치 / 세로축: 밝기)
✓

헤일로 영역에서 자동 제거되는 이유 — 헤일로는 수십~수백 픽셀에 걸쳐 완만하게 밝기가 변합니다. bg_kernel이 71px 이상이면 가우시안 블러가 이 완만한 기울기를 그대로 따라가므로, 헤일로 픽셀의 잔차(local_bg − pixel)는 거의 0이 됩니다. 반면 PSL 파티클은 1~5픽셀 규모의 급격한 어두운 점이므로 가우시안이 완화하지 못해 잔차가 양수로 남습니다.

Parameter

배율 선택

배율 선택 mag x50 / x100 / x200 / x500 / x1000
배경

현미경 배율이 달라지면 같은 물리적 파티클이 이미지에서 차지하는 픽셀 수가 완전히 달라집니다. x50에서 1.6px로 보이는 PSL 파티클이 x1000에서는 32px가 됩니다. 따라서 검출 파라미터(커널 크기, 임계값, 면적 필터)를 배율마다 따로 저장해야 합니다.

작동 원리

배율을 선택하면 Setting Manager에 저장된 해당 배율의 레시피(파라미터 세트)가 자동으로 슬라이더에 적용됩니다. 동시에 Calibration 데이터(px/mm)도 불러와 파티클 크기 필터와 좌표 변환에 사용됩니다.

실무 지침

배율 전환 시 반드시 해당 배율용 Calibration을 완료해야 파티클 크기 필터(목표 파티클 크기 항목 참고)가 정확하게 동작합니다. Calibration이 없는 배율은 버튼이 회색으로 표시됩니다.

Parameter

목표 파티클 크기

목표 파티클 크기 pdiam 0.1 — 50.0 μm
기본값1.5 μm
단위마이크로미터 (μm)
의존Calibration (px/mm) 완료 필요
배경

PSL 파티클 검사에서는 특정 직경의 파티클만 계수해야 합니다. 노이즈, 먼지, 기판 스크래치 같은 이물질이 파티클로 잘못 검출되는 문제를 줄이기 위해 최소 면적 필터를 적용합니다.

작동 원리

입력된 직경(μm)과 Calibration 값(px/mm)으로 파티클의 이론적 픽셀 면적을 계산합니다.

# 반지름 (픽셀)
r_px = (pdiam × px_per_mm / 1000) / 2
# 최소 면적 필터
min_area = π × r_px²

컨투어 면적이 min_area보다 작은 blob은 파티클로 인정하지 않습니다. 이 필터 하나만으로 단발성 노이즈 픽셀의 대부분을 제거할 수 있습니다.

조정 지침
크게 설정할 때

목표 파티클이 클수록 / 미세 노이즈를 더 적극적으로 제외할 때. 단, 실제 파티클도 필터링될 수 있음.

작게 설정할 때

배율이 낮아 파티클이 1~2픽셀로만 보일 때. 지나치게 낮으면 노이즈 오검출 증가.

Parameter

배경 추정 커널

배경 추정 커널 bg_kernel 11 — 201 px (홀수만)
기본값71 px
단위픽셀
제약항상 홀수 처리됨
배경

배경 대비법의 핵심은 "로컬 배경을 얼마나 정확하게 추정하느냐"입니다. 로컬 배경은 대형 가우시안 블러로 추정하는데, 이 블러의 커널 크기가 bg_kernel입니다.

커널이 너무 작으면 파티클 자체가 블러에 포함되어 배경 추정값이 낮아지고, 잔차(residual)가 줄어 파티클을 놓칩니다. 커널이 너무 크면 연산 시간이 길어지고, 이미지 경계 근처에서 왜곡이 생깁니다.

작동 원리

가우시안 커널은 중심에서 멀어질수록 가중치가 줄어드는 원형 필터입니다. bg_kernel=71이면 반경 35픽셀 내의 밝기를 가중평균한 값이 해당 픽셀의 "로컬 배경"이 됩니다.

📐

경험칙 — bg_kernel은 파티클 직경의 픽셀값 기준으로 최소 10배 이상 크게 설정해야 파티클 자체가 블러에 흡수되지 않습니다. x100에서 PSL 1.5μm가 약 5픽셀이라면, bg_kernel ≥ 51 이상 권장.

헤일로와의 관계

홀 주변 헤일로는 보통 수십~수백 픽셀 범위에 걸쳐 완만하게 밝기가 변합니다. bg_kernel이 헤일로 폭보다 같거나 크면, 가우시안 블러가 헤일로 기울기를 그대로 따라가므로 헤일로 픽셀의 잔차가 0에 가깝게 유지됩니다.

배율별 가이드
배율권장 bg_kernel이유
x5051파티클 픽셀 수 적어 큰 커널 불필요, 헤일로 폭도 좁음
x10071기본값. 9홀 이미지에서 검증된 값

조정 지침
크게 설정할 때

헤일로 범위가 넓고 조명 불균일이 심할 때. 헤일로 내부 파티클이 검출되지 않을 때.

작게 설정할 때

파티클이 크거나(고배율) 이미지가 균일할 때. 처리 속도 개선 필요 시.

Parameter

배경 대비 임계값

배경 대비 임계값 res_th 3 — 100
기본값25
단위그레이스케일 밝기 차이 (0–255)
권장 범위15 — 40
배경

배경 대비법으로 계산된 잔차(residual) 이미지는 각 픽셀이 로컬 배경보다 얼마나 어두운지를 나타냅니다. res_th는 "이 정도 어둡면 파티클로 인정한다"는 기준입니다.

기존 전역 임계값(th)이 절대 밝기를 비교했다면, res_th는 상대적 어두움을 비교합니다. 덕분에 조명 불균일이나 배율 변경에 따른 전반적 밝기 변화에 강건합니다.

작동 원리

잔차값이 res_th를 초과하는 픽셀만 이진 마스크에 포함됩니다. 이 마스크에서 연결된 픽셀 덩어리(컨투어)를 찾아 파티클 후보로 처리하고, 이후 면적 필터(pdiam 기반)와 홀 마스크를 적용합니다.

⚠

주의 — res_th를 낮출수록 검출 민감도가 높아지지만, 배경 노이즈(카메라 센서 노이즈, BMP 포맷에서도 존재)도 파티클로 오검출될 수 있습니다. 이미지 포맷이 JPG라면 DCT 블록 노이즈(8×8px 격자) 때문에 노이즈 임계가 더 높습니다.

조정 지침
높게 설정할 때

배경 노이즈가 많거나 JPG 이미지를 사용할 때. 오검출(false positive)을 줄이고 싶을 때.

낮게 설정할 때

배경이 깨끗한 BMP/PNG 이미지일 때. 미검출(false negative)을 줄이고 싶을 때. PSL 입자 대비가 낮을 때.

Parameter Group

이미지 보정

전처리 단계에서 원본 이미지에 적용되는 밝기/대비/블러 조정입니다. 검출 알고리즘 실행 전에 적용되므로 결과 전체에 영향을 줍니다.

밝기 br −100 — +100
기본값0
배경 및 작동 원리

그레이스케일 변환 후 모든 픽셀에 br 값을 더합니다. 카메라 노출이 전반적으로 어둡거나 밝게 촬영된 경우 보정 용도입니다. 배경 대비법 자체가 로컬 배경을 기준으로 동작하기 때문에 전반적 밝기 오프셋에는 강건하나, 극단적으로 어두운 이미지라면 사전 보정이 도움이 됩니다.

대비 ct 0.5 — 3.0
기본값1.0
1.0 = 변화 없음
배경 및 작동 원리

픽셀 밝기를 128 기준으로 스케일합니다: new = 128 + ct × (pixel − 128). 대비를 높이면 파티클과 배경의 밝기 차이가 커져 잔차 계산에서 파티클이 더 선명하게 분리됩니다. 단, 과도한 대비는 포화(saturation)를 유발하여 배경 추정을 왜곡할 수 있습니다.

블러 bl 0 — 15 px (홀수만)
기본값0 (비활성)
배경 및 작동 원리

가우시안 블러를 이미지 전체에 적용합니다. 배경 대비법에서는 bg_kernel이 이미 내부적으로 블러를 사용하므로, bl은 카메라 센서 노이즈가 극심한 경우 보조적으로만 사용합니다. BMP/PNG처럼 무손실 포맷에서는 일반적으로 0을 유지합니다.

⚠

bl이 크면 파티클 자체가 흐려져 잔차값이 감소합니다. res_th와 역방향으로 작용하므로 동시에 조정할 때 주의하십시오.

Parameter

홀 감지 임계값

홀 감지 임계값 hole_thr 60 — 180
기본값120
대상TGV 홀(구멍) 위치 자동 검출
배경

TGV 기판의 홀은 관통공이므로 현미경 이미지에서 매우 밝은 원형 영역으로 나타납니다. 이 홀과 홀 주변 림(rim)을 파티클 검출 영역에서 제외하지 않으면 홀 경계의 밝기 변화가 파티클로 오검출됩니다.

hole_thr은 HoughCircles 전처리용 이진화 임계값입니다. 이 값으로 이진화한 이미지에서 원형 패턴을 탐지하여 홀 위치와 반경을 자동으로 결정합니다.

작동 원리

그레이스케일 이미지를 hole_thr로 이진화(THRESH_BINARY) → 에지 검출 → HoughCircles로 원 후보군 탐색 → 반경 기준 필터링. 가장자리에 걸친 반원(edge hole)은 별도 플래그(is_edge)로 표시하고, 통계에서 제외합니다.

조정 지침
높게 설정할 때

홀 외부 헤일로까지 밝아서 홀 경계가 불분명할 때. 홀이 더 선명하게 탐지됨.

낮게 설정할 때

홀 내부 조명이 고르지 않거나 림 자체가 어두울 때. 홀 미검출 시 낮춰서 재시도.

Parameter

홀 마스크 여유

홀 마스크 여유 hole_margin 0 — 60 px
기본값30 px
적용 범위검출된 홀 반경 + hole_margin
배경

HoughCircles가 검출한 홀 반경은 림(rim)의 안쪽 경계입니다. 림 자체의 두께와 홀 경계 직후의 헤일로 전이 구간을 제외하려면 추가 여유 픽셀이 필요합니다.

v4.3 이전에는 가장자리에 가까운 홀에 대해 rim_search 영역을 적응적으로 키우는 복잡한 로직이 있었으나, 배경 대비법이 헤일로를 자동으로 처리하므로 단순 고정 여유값으로 대체되었습니다.

작동 원리

각 홀에 대해 반경 r + hole_margin인 원형 마스크를 생성하고, 이 영역 내부의 파티클 후보를 검출 결과에서 제외합니다. 결과 이미지에는 내원(홀 경계)과 외원(실제 마스크 경계) 두 개의 원이 표시됩니다.

조정 지침
크게 설정할 때

림 두께가 두껍거나 홀 경계 직후에 헤일로 오검출이 남아있을 때.

작게 설정할 때

홀 바로 근처의 실제 파티클을 검출해야 할 때. 최소값 0은 림 경계까지만 제외.

Parameter

가장자리 여백

가장자리 여백 margin 0 — 300 px
기본값0 (전체 검사)
배경 및 작동 원리

이미지 네 변에서 margin 픽셀만큼 안쪽 영역만 검사합니다. 현미경 이미지의 가장자리는 비네팅(vignetting), 렌즈 왜곡, 조명 불균일이 집중되는 구역입니다. 이 구역의 밝기 변화가 파티클로 오검출되는 경우 margin으로 배제할 수 있습니다.

0이면 이미지 전체를 검사합니다. 0보다 크면 상태 표시줄에 "가장자리 XXpx 제외 중"이라고 표시됩니다.

Parameter

파티클 색상

파티클 색상 particle_color_hex 6가지 프리셋
기본값초록 #3cdc00
저장배율별 레시피에 포함
배경

PSL 파티클이 시료 배경과 같은 색조를 가질 경우, 검출 결과 이미지에서 파티클 표시가 배경에 묻혀 시각 확인이 어렵습니다. 특히 청색 계열 필터를 사용하는 이미지에서 초록색 마커가 잘 보이지 않는 경우가 있어 색상 선택권을 추가했습니다.

Feature

리터칭 (수동 파티클 추가 / 제거)

파티클 리터칭 확대 보기 창 전용 파티클 검출 결과 패널 한정
배경

자동 알고리즘은 통계적 최적값으로 설정되어 있어, 특수한 오염 형태나 극단적 이미지 조건에서 작업자의 육안 판단과 결과가 다를 수 있습니다. 리터칭은 알고리즘 파라미터를 전체적으로 바꾸지 않고 개별 파티클 단위로 결과를 보정하는 최후 수단 도구입니다.

Feature

수동 제외 영역

수동 제외 영역 exclusions 우클릭 드래그로 원형 영역 지정
배경 및 작동 원리

홀로 검출되지 않은 구조물(스크래치, 필드 외부 마킹, 테스트 패턴 등)을 검출 영역에서 임시로 제외할 때 사용합니다. "편집 모드 ON" 상태에서 ③ 결과 이미지 위에서 우클릭 드래그하면 원형 제외 영역이 생성됩니다. "초기화" 버튼으로 전체 제거합니다.

제외 영역은 홀 마스크와 동일한 방식으로 검출에서 배제되며, 주황색 원과 가로선으로 표시됩니다. 이미지가 바뀌면 자동으로 초기화됩니다.
