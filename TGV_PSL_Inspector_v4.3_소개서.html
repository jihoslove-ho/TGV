TGV PSL Inspector
파티클 자동 검출 소프트웨어

유리기판(TGV) 세정 공정 평가에 특화된 PSL 파티클 자동 카운팅 소프트웨어입니다. 고배율 비접촉 측정기와 함께 제공되어, 이미지 촬영부터 Excel 보고서까지 하나의 환경에서 완결됩니다.

대상 기판TGV(Through Glass Via) 유리기판
검사 입자PSL (Polystyrene Latex Sphere)
측정기 동반 제공고배율 비접촉 측정기와 패키지 공급
사용 배경

어떤 목적으로 사용하는가

1
TGV 유리기판 미세홀 세정 공정 평가
TGV 공정에서 형성한 미세홀(Via) 내부의 잔류 파티클을 제거하는 세정 공정의 성능을 정량적으로 평가하기 위해 PSL 파티클을 기준 입자로 사용합니다.
2
PSL 파티클 기반 세정 효율 측정
세정 전 기판에 부착한 PSL 파티클의 수와, 세정 후 잔여 파티클의 수를 비교하여 세정 효율을 수치로 확인합니다. 이 과정에서 현미경 이미지의 파티클을 정확히 카운팅하는 것이 핵심입니다.
3
고배율 비접촉 측정기 + 소프트웨어 패키지 공급
TGV 미세홀 관찰·촬영용 고배율 비접촉 측정기와 PSL Inspector 소프트웨어를 함께 공급합니다. 측정기로 획득한 이미지를 소프트웨어가 자동으로 분석하여 파티클 검출·카운팅·보고서 저장까지 처리합니다.
📦
패키지 공급 구성
고배율 비접촉 측정기 (TGV 미세홀 관찰·촬영용)　＋　TGV PSL Inspector 소프트웨어
별도 설치 없이 단일 실행 파일(EXE)로 즉시 사용 가능합니다.
화면 구성

소프트웨어 실제 화면

이미지 로드 즉시 홀 자동 검출과 파티클 검출이 실행되며, 결과가 3개 패널에 나란히 표시됩니다.

TGV PSL Inspector v4.3
▲ 실제 소프트웨어 화면. 좌측: 파일 목록 & 배율별 레시피 · 중앙: 3단 이미지 패널 · 우측 하단: 파라미터 · 검출 결과 테이블

세 패널은 각각 다음 역할을 합니다:

① 원본 이미지
② 이진화 프리뷰
③ 파티클 검출 결과
주요 기능

기능별 상세 설명

자동 검출
🔵
홀(Hole) 자동 검출
이미지 내 원형 홀의 위치와 반경을 자동으로 인식합니다. 기판 가장자리의 반원(Edge hole, 주황색 표시)도 별도 처리합니다. 홀 내부와 주변 여백(Hole margin)은 검사 대상에서 자동 제외됩니다.
자동 / 수동 전환 가능
▲ 확대 보기 화면 — 파란 원: 홀 마스크 경계, 주황 원(E): 가장자리 반원, 초록 점: 검출된 파티클
🔬
PSL 파티클 자동 검출
배경 대비 알고리즘으로 홀 주변 조명 할로(halo) 구역에서도 파티클을 정확하게 찾습니다. 파라미터를 바꾸면 이진화 프리뷰(②패널)에 결과가 즉시 반영되어, 흰 점의 분포를 보면서 최적 민감도를 실시간으로 확인할 수 있습니다.
실시간 프리뷰 연동
▲ 이진화 프리뷰(②) — 흰 점 하나가 파티클 후보 1개. 홀 영역은 자동 마스크 처리
검사 조건 설정
🎚
파라미터 실시간 조정
파티클 최소 직경(pdiam), 배경 커널 크기(bg_kernel), 배경 대비 임계값(res_th), 홀 감지 임계값, 홀 마스크 여유 등을 슬라이더와 수치 입력 필드로 즉시 조정합니다. 값을 바꾸는 즉시 이진화 프리뷰가 갱신됩니다.
11개 파라미터
💾
배율별 레시피 저장
Setting Manager에서 x50, x100, x200, x500, x1000 각 배율별로 최적 파라미터 세트를 저장합니다. Calibration(px/mm 변환 계수)도 배율별로 저장되어, 배율 선택 즉시 모든 조건이 자동 로드됩니다.
x50 / x100 / x200 / x500 / x1000
⛔
수동 제외 영역 지정
스크래치나 이물질처럼 파티클이 아닌 구조물이 오검출될 경우, 해당 위치에 원형 제외 영역을 직접 지정합니다. 지정 영역 안의 검출 후보는 결과에서 제외되며, 복수 설정과 해제가 모두 가능합니다.
복수 영역 설정 · 즉시 해제
이미지 편집
✂️
이미지 자르기 (Crop)
원본 이미지에서 검사할 관심 영역을 드래그로 선택합니다. 8개 핸들로 정밀하게 영역을 조절할 수 있으며, 자르기를 적용하면 해당 영역만 검사 대상이 됩니다. 원본은 자동 백업되어 "원본 복원" 버튼으로 언제든 되돌릴 수 있습니다.
원본 자동 백업 · 복원 가능
▲ 이미지 자르기 창 — 8개 핸들(초록)로 영역 조절 · 3×3 가이드선 · 원본 복원 / 취소 / 적용 버튼
🔍
확대 보기 및 수동 리터칭
파티클 검출 결과를 별도 창에서 확대하여 세밀하게 확인합니다. 배율 선택(50%~300%), 슬라이더로 자유로운 탐색이 가능하며, "+ 파티클 추가" / "− 파티클 제거" 버튼으로 자동 결과를 보정할 수 있습니다.
추가 · 제거 리터칭 가능
▲ 파티클 검출 결과 확대 보기 — 초록 점: 파티클, 파란 원: 홀 마스크, 주황 원(E): 가장자리 반원
검사 및 보고
📁
폴더 일괄 검사
폴더 안의 이미지 파일 전체를 현재 파라미터로 순차 자동 검사합니다. 완료 시 전체 이미지의 결과가 Excel 파일에 자동 저장됩니다. 상단 상태 표시줄에서 현재 이미지의 파티클 수와 홀 정보가 실시간으로 표시됩니다.
Excel 자동 저장 포함
📊
Excel 자동 보고서 생성
폴더 일괄 검사 완료 시 이미지명, 파티클 수, 각 파티클의 번호·좌표(px/mm)·크기를 Excel로 자동 생성합니다. 세정 전후 데이터를 즉시 비교 분석할 수 있습니다.
번호 · 좌표 · 크기 · 이미지명 자동 기록
사용 흐름

기본 검사 순서

처음 사용 시 배율별 레시피를 Setting Manager에서 설정하면, 이후에는 폴더 로드 → 검사 실행 → 보고서 저장의 3단계로 운용됩니다.

1
폴더 로드
이미지 폴더 선택 후 파일 목록 자동 표시
2
배율 선택
촬영 배율 버튼 클릭 → 레시피 자동 로드
3
검사 실행
홀 자동 검출 후 파티클 검출 및 결과 표시
4
결과 보정
확대 보기에서 리터칭으로 판정 보정
5
보고서 저장
전체 폴더 검사 결과 Excel 자동 저장
검사 결과물

소프트웨어가 제공하는 것

① 파티클 검출 이미지
검출된 파티클마다 번호와 색상 원이 표시된 결과 이미지. 홀 경계, 가장자리 반원, 제외 영역을 구분 색상으로 표시합니다.
② 파티클 데이터 테이블
번호·좌표(px, mm)·크기를 화면 내 테이블로 즉시 확인. 항목 클릭 시 해당 파티클 위치로 이동합니다.
③ Excel 자동 보고서
이미지명·파티클 수·개별 좌표·크기가 기록된 Excel 파일. 폴더 일괄 검사 완료 후 자동 생성됩니다.
